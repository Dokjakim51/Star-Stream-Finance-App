# Publicar Star Stream en GitHub más adelante

## Datos sugeridos del repositorio

- **Nombre:** `Star-Stream-Finance-App`
- **Descripción:** `Aplicación de finanzas personales desarrollada con Google Apps Script, JavaScript y Google Sheets. Dashboard responsive, cuentas, metas, planificación y gráficos.`
- **Visibilidad:** `Public` (únicamente el código fuente, nunca los datos de producción).
- **Temas:** `google-apps-script`, `javascript`, `personal-finance`, `google-sheets`, `dashboard`, `web-app`, `responsive-design`.

## Al momento de subirlo

1. Extrae el ZIP en tu computadora.
2. Si ya tienes una copia de trabajo, conserva este ZIP como versión pública separada.
3. Crea el repositorio en GitHub y sube los **archivos contenidos en la carpeta**, no el ZIP entero.
4. Revisa que se vean `Code.gs`, `Database.gs`, `index.html`, `scripts.html`, `styles.html` y `README.md`.
5. No subas la carpeta `.venv`, exportaciones financieras, `.clasp.json`, identificadores privados ni contenido de Google Drive.
6. El `README.md` se mostrará automáticamente en la portada.
7. Puedes tomar capturas para el README desde una **instalación independiente con datos ficticios**.

> El repositorio GitHub sí puede ser público. La Web App vinculada a tu cuenta y a tus finanzas debe mantenerse restringida a ti.

## Qué contiene esta versión

- Interfaz gráfica v0.8.18 con la pantalla y el botón de bloqueo retirados.
- Backend completo de fase 8 con migración y funciones de datos.
- Documentación de instalación y advertencias de seguridad.
- Tests estáticos y una acción de GitHub que los ejecuta cuando se suba el repositorio.
